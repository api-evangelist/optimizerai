# OptimizerAI

> OptimizerAI is an AI-powered sound effects (SFX) foundation model that generates unlimited, high-quality, royalty-free audio from text prompts or reference audio for game developers, video producers, filmmakers, and other creators. Its text-to-sfx v2 model produces studio-quality stereo output at 44.1 kHz up to 60 seconds, with sound variations, style selection, and a "magic prompt" mode. OptimizerAI, Inc. offers a commercial, contract-based API authenticated with a project-specific API key over HTTPS. The company is backed by Andreessen Horowitz (a16z).

## APIs
- [OptimizerAI Text-to-SFX API](https://docs.optimizerai.xyz/api/pricing): Commercial sound-effects generation API (text-to-sfx v2). Contract-based access across Ultra-Fast/Fast (dedicated) and Slow (shared) tiers with monthly call allowances, overage pricing, and uptime SLAs. Auth: project-specific API key via HTTPS header.
